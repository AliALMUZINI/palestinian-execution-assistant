# مساعد التنفيذ الفلسطيني — نسخة مدمجة مع الأرشيف القانوني

مشروع مستقل لمساعدة المحامي في تحليل الوقائع التنفيذية، استرجاع المصادر الفلسطينية ذات الصلة، وصياغة المسودات باستخدام Gemini.

## ما تم دمجه في هذه الحزمة

- النص الكامل لقانون التنفيذ الفلسطيني رقم (23) لسنة 2005، باعتباره المصدر التشريعي الأعلى داخل الأرشيف.
- قانون التنفيذ رقم (23) لسنة 2005 وبيانات حالة النص والتعديل.
- قرار بقانون رقم (25) لسنة 2024 ضمن الأرشيف مع التنبيه إلى ضرورة التوحيد والتحقق الرسمي.
- أرشيف كتاب محمد أحمد حامد فروانة، صفحةً صفحةً، مع ملف PDF المرفوع للمشروع.
- أرشيف كامل لمرجع عثمان التكروري، مع نسخة PDF أصلية ونص قابل للبحث وفهرس بحسب الصفحة.
- أرشيف كامل لبحث حبس المدين، مع نسخة PDF أصلية ونص قابل للبحث وفهرس بحسب الصفحة.
- أرشيف كامل لشرح القاضي محمد أحمد حامد فروانة، مع نسخة PDF أصلية ونص قابل للبحث وفهرس بحسب الصفحة.
- فهرسة 79 سابقة تنفيذية مع التمييز بين الفهرسة والنص الكامل.
- مواد مجلس القضاء الأعلى/غزة الخاصة بالتنفيذ والتعاميم والإجراءات والتنفيذ الإلكتروني الموجودة في الأرشيف.
- حكم التنفيذ الإضافي في أرشيف غزة.
- قاعدة أرشيفية موحدة في `data/archive-index.json` تضم 1002 سجل صفحة يستخدمها محرك الاسترجاع المحلي.
- بحث حي اختياري عبر Google CSE عند وضع علامة «تفعيل البحث الحي على الإنترنت» ثم الضغط على زر التوليد.
- Gemini يعمل من الخادم، ولا يُكشف المفتاح للمتصفح.
- لوحة إدارة مباشرة بدون Supabase.
- إدارة المصادر المخصصة مع حفظ دائم اختياري عبر GitHub Contents API.

## النشر على Vercel
1. ارفع محتويات هذا المجلد إلى مستودع GitHub.
2. اربط المستودع بـ Vercel.
3. أضف متغيرات البيئة من `.env.example`، وعلى الأقل:
   - `GOOGLE_GENERATIVE_AI_API_KEY`
   - `GEMINI_MODEL`
4. لا ترفع ملف `.env` الحقيقي ولا مفتاح Gemini إلى GitHub.
5. لتفعيل البحث الحي، أضف `GOOGLE_CSE_API_KEY` و`GOOGLE_CSE_ID` في إعدادات Vercel فقط.

## الأرشيف القانوني

- الفهرس: `data/archive-index.json` (1002 صفحة مفهرسة).
- الملفات الأصلية والنصوص المفصّلة بحسب الصفحة: `data/legal-reference-archive/`.
- يعرض الموقع عنوان المرجع ورقم صفحة PDF للمقاطع التي استرجعها.
- المراجع الفقهية مساندة فقط؛ يجب التحقق من النص الفلسطيني النافذ قبل الاعتماد أو الإيداع.
