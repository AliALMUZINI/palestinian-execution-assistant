# مساعد التنفيذ الفلسطيني

واجهة عربية متجاوبة لمساعد قانوني مخصص لقضايا التنفيذ الفلسطينية، وتضم تحليل الوقائع، مسودات أولية قابلة للنسخ والطباعة، نماذج سريعة، ومحادثات محلية قابلة للاسترجاع أو الحذف.

## التشغيل والنشر

1. ارفع محتويات هذا المجلد إلى مستودع GitHub.
2. في Vercel، استورد المستودع.
3. أضف متغير البيئة `AI_GATEWAY_API_KEY` في إعدادات المشروع فقط، ولا تضعه في ملف مرفوع إلى GitHub.
4. نفّذ النشر. ستعمل واجهة الموقع على الجوال والكمبيوتر.

عند غياب المفتاح، تعرض الواجهة مسودة تدريبية محلية، ولا تُرسل المفتاح إلى المتصفح مطلقاً. أما مع ضبط المفتاح على منصة النشر فيعمل التوليد الذكي من خلال مسار خادمي آمن.

## إدارة البيانات

الجلسات في النسخة الحالية محفوظة داخل متصفح المستخدم فقط ويمكن حذفها بالكامل من الواجهة. لوحة إدارة متعددة المستخدمين، وتسجيل دخول، وقاعدة بيانات مركزية تحتاج ربطاً منفصلاً بقاعدة بيانات ومصادقة حقيقية؛ لا ينبغي استخدام كلمة مرور مضمّنة داخل ملف الواجهة كوسيلة حماية.

## ملاحظات مهنية

هذا المنتج للمساندة والتدريب فقط. يجب التحقق من قانون التنفيذ الفلسطيني رقم (23) لسنة 2005 وتعديلاته، ومن النصوص والأوراق الرسمية، قبل اتخاذ أو إيداع أي إجراء.
